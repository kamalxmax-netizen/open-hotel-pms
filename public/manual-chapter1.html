📋 Reservation — รับจอง

  • ไปที่เมนู Reservations
  • กด + New Booking มุมขวาบน
  • กรอก: ชื่อแขก, วันเข้า-ออก, ประเภทห้อง, Source (Walk-in / OTA / Direct)
  • บันทึก → ระบบสร้าง Booking ID ให้อัตโนมัติ เช่น BK-2026…

🛏️ Assign Room — จัดห้อง

  • ไปที่เมนู Arrivals
  • ถ้าเห็นปุ่มสีเทา "Assign Room" = ยังไม่ได้จัดห้อง
  • กด Assign Room → เลือกห้องที่ว่างและเหมาะสม
  • หรือใช้ Room Diary คลิกห้องว่างแล้วเลือก Assign

🚶 Check-in — เช็คอิน

  • ไปที่เมนู Arrivals → หาชื่อแขก
  • ตรวจสอบว่า Assign ห้องแล้ว (ปุ่มจะเปลี่ยนเป็นสีน้ำเงิน "Check-in")
  • กด Check-in → ระบบขอข้อมูลแขก
  • สแกนบัตรประชาชน (Thai ID Reader) หรือ Passport (OCR)
  • ยืนยัน → ห้องเปลี่ยนเป็น In-House ทันที

🏨 In-House — แขกพักอยู่

  • ดูรายชื่อแขกทุกห้องได้ที่เมนู In-House
  • กด Move Room หากต้องการย้ายห้อง
  • กด Options → เพิ่ม Extra Charge, ดู Folio, เพิ่ม Trace
  • ใช้ Logbook ฝากข้อความให้กะต่อไป

💳 Payment — ชำระเงิน

  • เปิด Folio แขกผ่าน Options → Folio / Payments
  • ตรวจสอบค่าใช้จ่ายทั้งหมด: ค่าห้อง + Extra Charges + POS
  • เลือกวิธีชำระ: Cash / Bank Transfer / Credit Card
  • กด Post Payment → ยืนยัน

🚪 Check-out — เช็คเอาท์

  • ไปที่เมนู Departures → หาชื่อแขก
  • ตรวจสอบ Folio ว่าชำระครบหรือยัง
  • กด Check-out → ยืนยัน
  • ห้องเปลี่ยนสถานะเป็น Dirty โดยอัตโนมัติ รอแม่บ้าน

🧹 Housekeeping — ทำความสะอาด

  • ระบบส่งงานไปที่ Housekeeping โดยอัตโนมัติ (Dirty Pool)
  • HK Supervisor Assign ห้อง Dirty ให้แม่บ้านแต่ละคนใน Timeline
  • แม่บ้านทำเสร็จ → กด Finish → Supervisor กด Approve
  • ห้องเปลี่ยนเป็น Clean ✓ พร้อมรับแขกใหม่
3 หน้าจอหลักแต่ละเมนู — ดู Live

คลิก tab เพื่อดูหน้าจอจริงแต่ละเมนู

openhotel.example/pms/board — Room Diary — แผนที่ห้องพัก
📸 Room Diary — แสดงสถานะห้องทุกห้องแยกชั้น คลิกห้องเพื่อดูรายละเอียดหรือ Assign ห้อง
สีสถานะห้องใน Room Diary:
Available — ห้องว่าง
Due In — กำลังมาวันนี้
In-House — พักอยู่
Dirty — รอทำความสะอาด
Due Out — กำลังออกวันนี้
Blocked — บล็อกห้อง
4 คำศัพท์สำคัญที่ต้องรู้

ค้นหาคำศัพท์ได้เลย หรือเลื่อนดูทั้งหมด

Reservation
การจองห้องพัก
การบันทึกว่าแขกต้องการพักในช่วงวันที่กำหนด ยังไม่ได้เข้าพักจริง ระบบสร้าง Booking ID ให้

Check-in
การเช็คอิน
กระบวนการรับแขกเข้าพัก ยืนยันตัวตน รับกุญแจ ห้องเปลี่ยนสถานะเป็น In-House ทันที
Front Desk
Check-out
การเช็คเอาท์
กระบวนการส่งแขกออก ชำระเงินครบ คืนกุญแจ ห้องเปลี่ยนเป็น Dirty โดยอัตโนมัติ

Folio

รายการค่าใช้จ่ายทั้งหมดในการเข้าพักครั้งนี้ ได้แก่ ค่าห้อง + Extra Charges + POS + Deposit
Front Desk
No-Show
แขกจองแต่ไม่มา
แขกที่จองห้องไว้แต่ไม่มาเช็คอินในวันที่กำหนด ต้องทำ Mark No-Show ใน Night Audit ทุกคืน

Manager
ADR
ราคาห้องเฉลี่ยต่อคืน

Manager
RevPAR
รายได้ต่อห้องพักทั้งหมด
Revenue Per Available Room = รายได้ ÷ ห้องทั้งหมด (รวมห้องว่าง) วัดประสิทธิภาพโดยรวม

ปิดยอดประจำวัน
กระบวนการปิดวันทางบัญชี 5 ขั้น: No-Show → Pre-Check → Preview → Confirm → Summary ทำทุกคืน

วันที่ที่ระบบใช้คำนวณทุกอย่าง อาจต่างจากวันจริงถ้ายังไม่ได้ทำ Night Audit

แขกที่เดินเข้ามาหาห้องพักโดยตรง ไม่ได้จองล่วงหน้า จะแสดง Source = Walk-in
Front Desk

เว็บจองออนไลน์

การเลือกเลขห้องจริงให้กับการจอง ต้องทำก่อน Check-in เสมอ ถ้ายังไม่ Assign จะ Check-in ไม่ได้

ห้องรอทำความสะอาด
สถานะห้องหลัง Check-out หรือใช้บริการ รอ Housekeeping ทำความสะอาดก่อนขายได้ใหม่
Housekeeping
Extra Charge
ค่าใช้จ่ายเพิ่มเติม
ค่าบริการนอกเหนือค่าห้อง เช่น อาหาร มินิบาร์ ค่าล่วงเวลา บันทึกใน Folio ของแขก
Front Desk
Deposit
เงินมัดจำล่วงหน้า
เงินที่แขกชำระล่วงหน้าก่อนเช็คอิน บันทึกในระบบเพื่อหักออกจาก Folio ตอน Check-out
Front Desk
